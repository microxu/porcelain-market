
# Porcelain Market

An e-commerce web application for selling collectible porcelain.

## Tech Stack
- Next.js 16 (App Router)
- Prisma + PostgreSQL
- NextAuth
- PayPal Sandbox
- Resend Email

## Features
- Product listing & detail
- Admin product management
- Cart & checkout
- PayPal payment integration
- Order management
- Admin dashboard with order status updates

## Setup

```bash
npm install
npm run dev

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
